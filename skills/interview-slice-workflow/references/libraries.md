# 视觉库与包装库

两个库从静态设计和动态行为分别积累，不把原片下载文件夹当库。

视觉卡：id、源案例/账号核验、实际封面/正文静帧、layout（画框、title/name/semantic/caption位置）、background（材料、空间、光）、fonts（实际身份/字重/未知）、color、hierarchy、subjectRelation、适用稿件、禁用情形、来源与权利、审查状态。

包装卡：id、动态可播放示例与确切时间、起止状态、durationFrames、easing、direction、layering、semanticTrigger、face/caption避让、exitBoundary、适配视觉卡、源案例证据和动态核查状态。只看一帧不能标动画已核验。

候选账号优先正式媒体/专业成熟栏目；核对原发布与账号身份，不把教程/搬运账号当高规格原样板。原链接失效时保留已有许可范围内的核验记录，不能编造视频内容。字体与音乐未知就写未知。

组合流程：稿件阶段命题→人物机位/留白→视觉卡→字长与字幕空间测量→兼容包装卡→实际预览→按稿件优化。两条差异至少比较颜色之外的构图、身份条和提炼组；不是随机拼风格。

本包内两种功能构图不替代真实高规格案例库，也不把作者项目的私有参考片直接公开。用户已有案例库留在其媒体库，通过配置引用。
